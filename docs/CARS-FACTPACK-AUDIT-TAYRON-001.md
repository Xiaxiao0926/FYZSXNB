## 5. 新增核心模块：俄罗斯进口历史与宏观背景 (New Module 10)

针对俄罗斯车主“为什么俄罗斯突然满大街都是中国造大众探岳”的深层疑问，在 Fact Pack 中正式增补 **Module 10: Russia Import History**：

```markdown
### 模块 10：俄罗斯进口历史与渠道演变 (Russia Import History)

#### 10.1 历史时间线与供应断裂 (Historical Timeline)
- **2022 年以前（官方合资时代）**：大众集团在俄罗斯卡卢加（Kaluga）工厂本土化组装欧版 Tiguan 与 Polo。俄罗斯消费者高度认可 MQB 平台与 TSI+DSG 动力组合，Tiguan 年销量常年位居俄合资紧凑型 SUV 前三位；
- **2022 年 3 月以后（供应真空期）**：大众集团暂停在俄工厂生产并退出俄罗斯官方业务（卡卢加资产最终出售给 AGR Automotive Group）。欧版新车正规供应彻底中断，二手途观车价飙升 40%~60%；
- **2022 年底 - 2023 年初（中国渠道破局）**：俄罗斯大型汽车经销商（如 Rolf, Avtodom, Major）与远东平行进口商将目光转向中国。中国作为全球唯一拥有大众全套完整产线与充足产能的市场，一汽-大众探岳 (Tayron) 与上汽大众途岳 (Tharu) 开始通过满洲里、霍尔果斯口岸大规模涌入俄罗斯。

#### 10.2 中国渠道的角色与流通形态 (Sourcing Channels)
1. **0公里准新车平行进口 (Parallel Import of 0-km Vehicles)**：
   - 进口商在中国以企业名义批量采购新车挂牌，随后以二手准新车（0-km used cars）形式办理海关出口手续，陆运直达莫斯科；
2. **欧亚经济联盟 (EAEU) 中转演变**：
   - 2022-2023 年主要经哈萨克斯坦、吉尔吉斯斯坦或白俄罗斯中转清关；2024-2026 年随着俄罗斯报废税（Утильсбор）新政与清关合规收紧，更多车辆转向中俄口岸直接正规清关；
3. **俄罗斯用户的选择动因 (Buyer Drivers)**：
   - **价格与供应**：在 300万~400万 卢布预算内，欧洲本土二手途观车龄长、里程高，而中规探岳为全新/准新车；
   - **底盘与空间优势**：探岳 2731mm 加长轴距相比老款欧版途观（2678mm）空间优势巨大，完美契合俄罗斯家庭长途出行需求；
   - **核心总成纯正性**：虽然在中国组装，但发动机（EA888 Gen3B）与变速箱（DQ381 湿式 7 速）与德国大众全球标准完全一致，机械素质远超同价位二手日系 CVT 车型。
```

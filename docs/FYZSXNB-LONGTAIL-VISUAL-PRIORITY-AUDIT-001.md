## 一、审计背景与核心目的

FYZSXNB 知识库已完成 **55 个核心页面与高价值文章** 的 Visual System 2.0 规范化升级（汽车生态与维修知识库 100%、工业供应链 100%、核心医疗合规 100%）。

本审计针对剩余未升级的 **60 篇长尾文章** 实施严格的**视觉投资优先级（ROI）排序**：
- **核心目的**：**拒绝盲目 100% 机械配图**，将高质量视觉生产资源精准倾斜至**高搜索价值、高商业转化潜力和高视觉必要性**的内容资产；
- **投资原则**：商业与技术硬核内容给予工业级实景 + 2~3 张正文深度插图；历史虚构小说与无商业意图内容保持归档状态，零视觉资源浪费。

## 二、评估维度与评分标准 (0-15 分制)

| 评估维度 | 权重分值 | 评估标准与判定准则 |
|---|---|---|
| **1. SEO 搜索价值** | **0 - 5 分** | **高分 (4-5)**：包含精准技术型号、法规条款号、故障诊断码、备件替换词；<br>**低分 (1-2)**：短期快讯、宽泛概念、缺乏长尾搜索入口。 |
| **2. 商业与转化价值** | **0 - 5 分** | **高分 (4-5)**：能直接沉淀采购咨询、出海合规代理、备件外贸询盘或供应链合作；<br>**低分 (1-2)**：纯资讯、娱乐性内容。 |
| **3. 视觉必要性** | **0 - 5 分** | **高分 (4-5)**：涉及复杂硬件拆解、微观接口、流程时序、注册矩阵，无图严重影响理解；<br>**低分 (1-2)**：纯观点论述或小说文本。 |

### 分级门槛与处理标准：
- **Tier A (立即升级 · $\ge 12$ 分)**：**生产级 70% 实景 Featured Image + 2~3 张正文技术深度图**；
- **Tier B (后续升级 · 8 - 11 分)**：仅需生产级 Featured Image 封面；
- **Tier C (基础补齐 · 4 - 7 分)**：标准通用场景图或信息卡片补齐；
- **Tier D (保持归档 · $< 4$ 分)**：**保持归档状态，零视觉资源投入**。

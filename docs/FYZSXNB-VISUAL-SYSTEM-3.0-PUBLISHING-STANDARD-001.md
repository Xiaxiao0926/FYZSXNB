## 一、核心哲学与视觉底线

在 FYZSXNB，**图片不是装饰品，而是内容的第一生产力与商业转化的第一接触点**。

### 1. 核心三大使命
1. **秒懂主题**：用户在 0.5 秒内通过主画面确切理解文章所属领域与核心探讨的硬件/工艺/法规；
2. **拉升 CTR**：在 Google Discover、Yandex 搜索流与首页卡片中，以真实场景质感击败泛滥的假图套图；
3. **沉淀 B2B 定位**：传递“现场工程师”、“药政注册专家”、“供应链采购总监”的专业信任感。

### 2. 绝对禁止红线 (Zero-Tolerance Prohibitions)
- ❌ **严禁抽象概念图**：发光 DNA 螺旋、蓝色漂浮球棍分子、无场景 3D 悬浮芯片、网络线条球体；
- ❌ **严禁商业套图伪装**：假医生握手照片、假老外商务谈判假笑、医院挂号前台宣传画；
- ❌ **严禁冒充官方公文**：伪造 FDA/NMPA/EAEU/Roszdravnadzor 官方印章或红头公文样式；
- ❌ **严禁先发文后补图**：严禁文章先裸奔发布再“抽空补图”。**无合规视觉资产的文章一律禁止发布**。

## 三、五大行业视觉模板库 (Industry Template Library)

根据文章的产业垂直领域，强制套用对应的视觉模板与色彩规范：

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                          INDUSTRY TEMPLATE COLOR PALETTES                              │
├────────────────────────────────────────────────────────────────────────────────────────┤
│ [Template A: Automotive Eng.]    │ Accent: #f59e0b (Amber) / #ef4444 (Crimson)         │
│ [Template B: Automotive Market]  │ Accent: #0ea5e9 (Sky Blue) / #38bdf8 (Ice Blue)     │
│ [Template C: Industrial Supply]  │ Accent: #f97316 (Industrial Orange) / #64748b       │
│ [Template D: Regulatory Intel]   │ Accent: #0284c7 (Ocean Blue) / #6366f1 (Indigo)     │
│ [Template E: Biotech Intel]      │ Accent: #10b981 (Emerald) / #0ea5e9 (Cyan)          │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

### 1. Template A — Automotive Engineering (汽车工程与维修)
- **适用范围**：发动机大修、双离合变速箱（DQ381）、CAN 总线逆向、ADB 智驾刷写、ECU 故障诊断。
- **视觉主体 (70%)**：真实机修工位、微焊显微镜、OBD-II 诊断示波器、油污原厂总成、电路引脚图。
- **信息辅助 (30%)**：故障诊断码（DTC）、引脚电压、扭矩参数、固件版本号。
- **绝对禁止**：纯 3D 渲染图、无修车环境的纯白底零件。

### 2. Template B — Automotive Market (中国汽车出海与选购)
- **适用范围**：车型海外横评、平行进口验证、二手车车况核查、报废税（Утильсбор）测算。
- **视觉主体 (70%)**：真实铺装道路/雪地行驶场景、验车底盘举升机、EPTS 电子海关申报终端。
- **信息辅助 (30%)**：排量税率公式、进口综合税费差额、质保供应链网点分布。
- **绝对禁止**：汽车厂商官方展厅摆拍精修套图。

### 3. Template C — Industrial Supply Chain (工业备件与自动化)
- **适用范围**：压力变送器、高压软管接头、割灌机化油器、3D 打印机局域网改造、工业 PLC。
- **视觉主体 (70%)**：真实车间配电柜、重工业管道液压测试台、机加工零件卡尺实测。
- **信息辅助 (30%)**：4-20mA 信号回路图、M22/BSPP 螺纹规格、公差等级、替代选型矩阵。
- **绝对禁止**：蓝色科幻机房背景、虚假无接线的悬浮阀门。

### 4. Template D — Regulatory Intelligence (国际药政与市场准入)
- **适用范围**：FDA 境外药企注册（21 CFR 207）、NMPA UDI 贯标、欧亚联盟（EAEU）医疗器械过渡期、GDUFA 问询。
- **视觉主体 (70%)**：药企 QA 注册办公室、FDA 官方电子网关检索终端、D&B DUNS 核验文件、无菌包装赋码。
- **信息辅助 (30%)**：FEI 代码校验状态、60天审评时间轴、DI/PI 条码结构。
- **绝对禁止**：仿冒官方红头公文与大盖帽印章。

### 5. Template E — Biotech Intelligence (先进生物制造与 IVD)
- **适用范围**：CGT/CAR-T 制造、蛋白层析纯化、POCT 分子诊断快速 PCR、-80°C 航空冷链。
- **视觉主体 (70%)**：GMP A/B 级生物安全柜、密闭细胞扩增仪、常温冻干试剂盒、Envirotainer 温控集装箱。
- **信息辅助 (30%)**：VCN 拷贝数质控标准、LoD 检出限对比、FDORA 平台技术认定流程。
- **绝对禁止**：抽象发光双螺旋 DNA、卡通病毒球体。

## 四、新文章发布端到端 SOP 流程

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│ 1. 撰写完成  │ ──> │ 2. 匹配模板  │ ──> │ 3. 视觉 Brief│ ──> │ 4. 图像生成  │
│  Markdown    │     │ Template A-E │     │ 场景+HUD设计 │     │ Python Engine│
└──────────────┘     └──────────────┘     └──────────────┘     └──────────────┘
                                                                      │
┌──────────────┐     ┌──────────────┐     ┌──────────────┐            ▼
│ 8. 全网生效  │ <── │ 7. 缓存刷新  │ <── │ 6. 绑定发布  │ <── ┌──────────────┐
│  Live 200 OK │     │  Purge Cache │     │ Featured Post│     │ 5. 双重 QA   │
└──────────────┘     └──────────────┘     └──────────────┘     │ Semantic+Comp│
                                                               └──────────────┘
```

1. **Step 1: 模板匹配**：根据文章核心关键词，从 Template A~E 中指定唯一归属模板；
2. **Step 2: 编写视觉 Brief**：
   - 确定 70% 真实场景主体（如：吉利星越 L CMA 架构底盘实测）；
   - 确定 3 张 HUD 芯片的标题与说明文本；
3. **Step 3: 图像生成**：调用 Python 图像合成引擎生成 1200x675 高清图；
4. **Step 4: 双重质量审核**：通过 4-Question AI 审核法与合规审核；
5. **Step 5: 规范上传**：上传至 WordPress Media，录入标准 Title / ALT / Caption；
6. **Step 6: 绑定与正文配图**：绑定为 `featured_media`，长文必须插入至少 2 张正文解析图；
7. **Step 7: 缓存刷新与验收**：执行 FTP 模板部署与 LiteSpeed 缓存清理，验证 HTTP 200 与图片正常渲染。

## 五、正文技术插图标准 (In-Body Technical Figures)

所有深度分析文章（字数 > 1500 字）**严禁纯文字长文**，必须配备至少 2 张正文深度解析图：

### 1. 正文图类型推荐
- **Type 1: 故障排查/时序流程图 (Workflow)**：如 FDA GDUFA 60天受控问询决策树；
- **Type 2: 硬件分解/剖面结构图 (Schematic)**：如米家冲牙器高频微型水泵剖面；
- **Type 3: 技术参数与选型对照矩阵 (Spec Matrix)**：如舌拭子 vs 痰液 GeneXpert 灵敏度对比；
- **Type 4: 真实工况现场案例图 (Real-world Case)**：如现场 VFD 变频器 4-20mA 接线实操。

### 2. 正文图发布铁律
- ❌ **严禁直接把 Featured Image 缩放重复插在正文开头**；
- ✅ 正文图必须具备独立的图题（Figure 1, Figure 2）与详细的技术说明（Caption）。

## 六、AI 图像审核 4 问法 (Quality Assessment Rubric)

每张生成的图像在上传前，必须由审核人员/Agent 回答以下 4 个问题，任一回答“否”必须打回重做：

1. **Q1（领域辨识度）**：用户在不看标题的情况下，第一秒能否明确识别文章所在的工业/科技领域？
2. **Q2（目标受众痛点）**：画面中的核心元素是否直接触及工程师、注册总监、采购经理的具体技术痛点？
3. **Q3（真实工况还原）**：画面是否展现了真实的仪器、工厂、维修工位或实验室环境，而非概念化布景？
4. **Q4（AI 幻觉与防伪）**：画面中是否存在多手指、扭曲文字、虚假官方盖章等 AI 幻觉？

## 八、首页流与多语言展示均衡控制

- **视觉流韵律**：首页 Feed 流连续 4 篇文章中，**相同主色调的模板不得连续出现超过 2 次**；
- **双语对齐**：同一文章的 EN 版与 RU 版，若共用技术内核，可保持统一构图但 HUD 标签必须精准适配对应语言或采用国际通用术语（如 ECU, CAN, FDA, GMP）；
- **品牌中立锚点**：画面右上角统一打上 `FYZSXNB [CATEGORY] INTELLIGENCE` 水印，塑造独立智库与情报中枢形象。

## 1. 消费端行为演进分析 (Per-Consumer Analysis)

### 1.1 `language_attributes` (`<html>` `lang`)
- **改动前**：仅区分 Russian Target（输出 `lang="ru-RU"`）与其他（输出 Core 默认 `lang="en-US"`）。
- **改动后（Resolver V2）**：
  * `en` $\to$ `lang="en-US"`（与改动前 100% 一致）；
  * `ru` $\to$ `lang="ru-RU"`（与改动前 100% 一致）；
  * `zh` $\to$ `lang="zh-CN"`（**新增中文原生合规支持**）；
  * `unknown` $\to$ `lang="en-US"`（安全兜底，避免 HTML 属性缺失）。

### 1.2 `aioseo_facebook_tags` (`og:locale`)
- **改动前**：Russian Target 输出 `ru_RU`，其他保持 AIOSEO 默认 `en_US`。
- **改动后（Resolver V2）**：
  * `en` $\to$ `en_US`（100% 一致）；
  * `ru` $\to$ `ru_RU`（100% 一致）；
  * `zh` $\to$ `zh_CN`（**新增中文社交分享卡片支持**）；
  * `unknown` $\to$ `en_US`（安全兜底）。

### 1.3 `aioseo_schema_output` (Schema `inLanguage`)
- **改动前**：遍历 WebPage/Article 节点将 Russian Target 改为 `"ru-RU"`，其他保持 `"en-US"`。
- **改动后（Resolver V2）**：
  * `en` $\to$ `"en-US"`（100% 一致）；
  * `ru` $\to$ `"ru-RU"`（100% 一致）；
  * `zh` $\to$ `"zh-CN"`（**新增结构化数据中文声明**）；
  * `unknown` $\to$ `"en-US"`（安全兜底）。

### 1.4 Hreflang 与 Canonical
- **首页 Hreflang（11 ↔ 400）**：**保持完全原状（FROZEN）**。
- **文章级 Hreflang**：受 0.4.0 译文组契约管辖，无配对译文的文章保持 0 标签输出（留白）。
- **Canonical**：Self-Canonical 铁律不变，每篇文章指向自身的完整永久链接。

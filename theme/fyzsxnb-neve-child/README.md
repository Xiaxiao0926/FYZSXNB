# FYZSXNB Neve Child

Offline Phase 1 package for `FYZ-20260811-NEVE-DESIGN-SYSTEM-001`.

## Scope

- Loads a token-based editorial design layer after Neve 4.2.8.
- Styles the existing Neve header and footer without replacing their builders.
- Improves article title scale, reading width, body rhythm, tables, quotes and image captions.
- Replaces the visible email byline through Neve's supported author-meta filter.
- Does not alter dynamic-feed queries, language routing, SEO output, post content or the Neve parent theme.

## Deployment gate

Do not activate until PHP lint, an inactive-theme upload, before/after screenshots and rollback preparation are complete.
